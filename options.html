Abas usando câmera, microfone ou compartilhando a tela, e abas com texto digitado e não enviado, nunca são suspensas automaticamente.

Suspensas automaticamente

    Sobre os números

    A memória por aba é uma estimativa: 30 MB + heap JS + 1,5 MB por mil elementos + 25 MB por frame de terceiro. Navegadores não expõem a memória real por aba para extensões. Para números reais por processo, use o gerenciador de tarefas do navegador (Shift+Esc no Windows/Linux, menu Janela no macOS, about:processes no Firefox).
